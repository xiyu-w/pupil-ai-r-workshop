Teach from this workspace
Core Part I: about 108 minutes, plus discussion and breaks. The optional classroom design lab adds 20 minutes. Timing is a suggested plan, not a fixed pace.
  1. Ask students to predict or describe the task before consulting AI.
  2. Choose a help action in Teaching Mode. Let students work through a hint and reasoning before revealing starter or full code. Built-in guidance is curated; external AI conversations are optional.
  3. Run code and examine the contextual learning notices. Ask students to modify, rerun, and explain what changed. Use the missing-data AI challenge to critique a deliberately wrong claim.
  4. Open “Check your reasoning”; compare counts, labels, and assumptions.
  5. Save a script and describe what was changed and why.
Two complementary teaching structures
Purdue Part I supplies the curriculum: R literacy, data import, exploration, subsets, and missingness. The ARVO 2026 workshop supplies the optional critique sequence: generate an initial analysis, add missing design context, evaluate, and revise. ARVO explicitly supports either WebR or RStudio; this edition places its own R workspace alongside the lessons.
For the score-below-400 exercise, let students try the starter before choosing the worked answer. For missing data, keep the original 200-row object; compare the flawed 11-row subset with the corrected 8-row result.
Before teaching, start R on the workshop network and install the import packages once. If downloads are blocked, use the bundled script and data in desktop RStudio. Browser work is temporary; remind students to download code and exports.
